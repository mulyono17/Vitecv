# Arya Negoro — React IT Portfolio

Portfolio premium built with:
- React
- Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Jalankan di komputer

Pastikan Node.js terpasang.

```bash
npm install
npm run dev
```

Kemudian buka alamat localhost yang diberikan Vite.

## Build production

```bash
npm run build
npm run preview
```

## File utama

- `src/main.jsx` — komponen dan konten portfolio
- `src/index.css` — Tailwind + custom CSS
- `vite.config.js` — konfigurasi Vite/Tailwind
- `package.json` — dependencies dan scripts

Ganti email, social links, project, pengalaman, dan data personal di `src/main.jsx`.
